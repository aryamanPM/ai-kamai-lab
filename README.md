# AI Kamai Lab

Autonomous Instagram content operating system focused on practical AI for Indian SMBs, creators and professionals.

## Architecture

Research → Opportunity Scoring → Content Strategy → Script → Production → QA → Publishing → Analytics → Learning → Research

## Initial Content Pillars

- AI for SMB
- AI Productivity
- AI Money
- AI Tools
- AI News
- AI Education
- AI Automation

## Safety

The system does not automate fake engagement, spam comments, mass-following, or other artificial-growth tactics. Instagram publishing uses supported Meta APIs when credentials are configured.

## Status

MVP architecture initialized. Meta/Instagram credentials and publishing integration remain deployment configuration items.
